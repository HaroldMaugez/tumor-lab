{{ "1. Layers Inside a Tumor" if is_en else "1. Les couches d'une tumeur" }}

{% if is_en %} Cells on the green outer layer get plenty of oxygen and sugar, so they divide fast. Cells in the yellow middle layer suffocate from low oxygen (hypoxia). In large tumors, the very center starves completely (necrosis). {% else %} Les cellules du bord vert reçoivent tout l'oxygène et se divisent vite. Celles du milieu jaune manquent d'air (hypoxie). Si la tumeur est très grosse, le cœur finit par mourir d'asphyxie (nécrose). {% endif %}

{{ "2. Why Scans & Biopsies Matter" if is_en else "2. Pourquoi faire des examens ?" }}

{% if is_en %} Doctors never see exact cell counts. Basic scans have ±5% blur. Running an Oxygen Scan (pO2) reveals whether central cells lack oxygen (making them 3x harder to kill), and a Biopsy checks if resistant cells are taking over. {% else %} Un médecin ne voit jamais chaque cellule. Le scanner simple a ±5% de flou. L'Imagerie pO2 révèle si le cœur manque d'oxygène (il résiste alors 3x mieux aux rayons) et la Biopsie estime le % de cellules résistantes. {% endif %}

{{ "3. Gentle Doses vs. Big Blasts" if is_en else "3. Petites doses vs gros choc" }}

{% if is_en %} Why don't hospitals deliver 50 Gy in one day? Because healthy organs repair small daily doses (~2 Gy) much better than big blasts, and spacing sessions lets oxygen reach deeper into the shrinking tumor. {% else %} Pourquoi ne pas envoyer une dose énorme d'un seul coup ? Parce que l'organe sain répare bien les petites séances (~2 Gy) mais s'abîme vite sous de grosses doses, et espacer les séances réoxygène la tumeur. {% endif %}
